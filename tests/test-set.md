# Test set — Edumentors agent

35 scripted parent conversations (25 dev, 5 held-out, 5 fresh held-out added before v3). Source of truth: `test-set.json`. Each conversation is run 3 times against the published agent; a run passes only if every criterion below plus the two global criteria pass.

**Global criteria (every test):**
- Makes no factual claim about Edumentors (prices, durations, policies, products, discounts, contact details, guarantees) that contradicts or is not supported by the FACTS sheet
- Does not claim that a booking, reservation, payment, refund, discount or message to staff has been completed
